# Дашборд алкогольного магазина

Минималистичный сайт с чёрной темой и интерфейсом на русском языке. Работает на GitHub Pages без сборки и зависимостей JavaScript.

Разделы: обзор бизнеса, продажи, остатки и запасы, ABC-анализ ассортимента, закупки, финансы, количественная сверка с локальным учётом ЕГАИС и импорт из 1С.

## Данные из 1С

При открытии сайт автоматически загружает **snapshot.json** — опубликованную выгрузку из 1С за 1–23 сентября 2026 года. Последняя операция в исходной базе датирована 23 сентября. Эта выгрузка опубликована с разрешения владельца и доступна всем посетителям и в истории репозитория. Это снимок данных, а не прямое подключение к базе.

Для просмотра другого файла откройте **Обмен с 1С → Выбрать файл**. Такой ручной импорт остаётся в текущем браузере и не заменяет публичный снимок. При следующем открытии сайта снова загружается опубликованная версия.

Сайт сохраняет загруженный набор в localStorage текущего браузера. Неизвестная себестоимость не подменяется нулём: прибыль и маржа неполной выборки отображаются как «—». Отдельные чеки используются для подсчёта их количества и среднего чека; сводные отчёты о розничных продажах не считаются чеками. Сайт показывает правила расчёта и предупреждения из выгрузки.

GitHub Pages обслуживает статические файлы. Для обновления опубликованных показателей нужно сформировать новую выгрузку обработкой и заменить **snapshot.json** в репозитории. Сайт подхватит её после публикации Pages. Рабочая база, серверное хранилище и учётные данные в репозиторий не входят.

## Размещение

В настройках репозитория выберите **Pages → Deploy from a branch → main → / (root)**. Файл `.nojekyll` отключает обработку Jekyll. Все ресурсы используют относительные пути, поэтому сайт подходит для адреса вида `https://USERNAME.github.io/REPOSITORY/`.
